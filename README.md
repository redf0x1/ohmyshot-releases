### What's New in v1.26.3

- **More reliable post-copy handling** — Improved the step that hides the editor after copying, with better diagnostics if it fails.
- **macOS text recognition recovery** — When system recognition fails, an offline English backup is available. Normal system recognition keeps its existing language support.
- The intermittent Windows copy-button report is still under investigation. Follow-up Defender checks no longer reproduce the earlier security alert; see the [release notes](https://github.com/redf0x1/ohmyshot-releases/releases/tag/v1.26.3) for details and safety guidance.

### v1.26.2 Highlights

- **Shape fill transparency now matches your selection** — Rectangle and ellipse fills support every opacity level, including fully transparent, while their outlines stay visible.

### v1.26.1 Highlights

- **Capture without interruptions** — Capture shortcuts remain ready after a picker, Quick Markup, or Copy & Close action, without an extra key press.
- **Reliable text editing** — Long text, manual line breaks, native input methods, and resized text boxes keep the content and width you chose.
- **More precise annotations** — Drag callouts into place and set shape fill color and opacity independently.

### v1.26.0 Highlights

- **Quick Markup** — Select an area, annotate it, then copy or save without opening the full editor.
- **Complete annotation toolkit** — Use arrows, rectangles, pen, text, blur, crop, undo, and redo in the focused Quick Markup window.
- **Repeatable capture** — OCR, Quick Capture, and Quick Markup remain available across repeated uses.

### v1.25.1 Highlights

- **Combine screenshots** — Add multiple screenshots and make one combined image inside OhMyShot.
- **No more Paint workaround** — Arrange screenshots as Auto, Row, or Column directly from the Export panel.
- **Copy fix** — Copying a beautified screenshot with a background no longer stays loading forever.
- **Better reliability** — Combined images work more reliably with screenshots pasted from different apps.

### v1.25.0 Highlights

- **Annotation defaults** — Save your preferred text, shape, and arrow styles for the next annotation.
- **Line styles** — Use solid, dashed, and dotted lines for arrows, lines, rectangles, and ellipses.
- **Curved arrows** — Add adjustable curved arrows for clearer callouts.
- **Watermarks** — Add resizable text or image watermarks to screenshots.

### Installation

#### macOS
1. Download the `.dmg` file
2. Open and drag OhMyShot to Applications
3. If macOS shows "The application can't be opened":
  1. **Terminal (Recommended)**: Open Terminal and run:
    ```bash
    xattr -cr /Applications/OhMyShot.app
    ```
  2. **Right-click**: Right-click the app → Open → Open
  3. **System Settings**: Go to System Settings → Privacy & Security → click "Open Anyway"

#### Windows
1. Download the `.exe` installer
2. Run the installer
3. Follow the installation wizard

#### Linux
```bash
# Debian/Ubuntu
sudo dpkg -i OhMyShot_1.26.3_amd64.deb

# Fedora/RHEL
sudo rpm -i OhMyShot-1.26.3-1.x86_64.rpm


```

## Privacy

- No account required
- Works offline by default (Cloud Upload is optional)

If you enable Cloud Upload, your screenshot is uploaded to ImgBB to generate a shareable link.
